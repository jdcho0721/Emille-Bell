# 에밀레: 천년의 울림
### Emille — A Thousand-Year Resonance

국보 **성덕대왕신종(에밀레종)**의 네 성물 — 용뉴·연뢰·비천상·당좌 — 을 소리와 해설로 만나는 다감각 미디어아트입니다.
종 표면에 새겨진 전통 문양의 구조적 미학을 전통 국악 선율과 앰비언트 사운드로 옮겨, 시각 너머의 사유와 울림을 전합니다.
시각장애인 관람객이 화면 읽기 프로그램을 쓰거나 쓰지 않거나, 소리와 자막만으로 끝까지 감상할 수 있도록 만들었습니다.
